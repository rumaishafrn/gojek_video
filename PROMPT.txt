TECHNIQUES (measured from the reference; reproduce their feel exactly)
- T1 Grid unpack: tiles rise from below the screen's bottom edge as a tight cluster and expand into the grid. 0.35 s, ease-out, stagger 50 ms.
- T2 Icon burst: tiles lift off the glass toward the camera (z-pop with parallax), scale up fast and fly past the lens with motion blur. ≈0.8 s, stagger 60 ms.
  - Each tile is drawn in stage space once it leaves the screen, with perspective scale F/(F − z).
  - Reverse T2 = the same in reverse, with objects converging from beyond the camera into a target.
- T3 Grow-from-element: a new card or banner grows out of the element that is already there. The element stays put while the card expands from it and its text reveals left to right. 0.3–0.4 s.
- T4 Drop-in: the glossy clock slides down from above the screen's top edge. 0.25 s, ease-out.
- T5 Barrel roll: the card is a band wrapped on a horizontal cylinder whose axis is tilted 12°, and it rotates one face per step.
  - Draw the outgoing and incoming faces as 48 horizontal strips. Each strip sits at y = R·sin φ, with height ∝ cos φ and brightness × (0.55 + 0.45·cos φ), so text bends and squashes as it rolls.
  - The leading edge gets a bright white/mint refractive rim (2–3 px, glow 10).
  - One step = 0.22 s (service and payment rolls) or 0.25 s (clock digits, staggered 40 ms right to left).
- T6 Liquid-glass lens bloom: a circle grows from the source element's centre until it covers the screen (0.5 s, ease inOut). Inside it is the next state. It has a thick refractive rim (≈26 units):
  - the next state magnified 1.12× about the centre, clipped to the rim annulus
  - an inner white → mint gradient stroke and a soft dark outer shadow
  - the rim arc stays visible as it sweeps past the screen corners
- T7 Defocus switch: blur 0 → 14 px → 0 over 0.35 s with an 8% darkening; swap the state at the peak.
- T8 (the reference's in-screen pan) is not used in this film.
- T9 Match morph: a real object (the dish photo) shrinks into a circle, desaturates, and its silhouette collapses into a glyph inside a frosted circle. 0.5 s.
- T10 Icon swap:
  - The old glyph spins ≈45°, shrinks to 0.3 and flies up-right while fading.
  - A Gojek-green conic arc sweeps 0 → 360° around the inside of the glass ring and fills to a disc.
  - The new glyph pops in (0.6 → 1, ease-out). ≈0.6 s in total.
- T11 Pass-through: the camera pushes until the bezel leaves the frame, then a soft white bloom (0 → 0.6 → 0 over 0.3 s), and the screen's world continues full-frame in stage space.
- T12 Draw-on: routes and lines draw from their origin. 0.2–0.3 s per segment, ease-out.
- T13 Slide-in with smear: map layers whip into place along one direction with directional motion blur. 0.3 s.
- T14 Follow-cam / pull-out / app close:
  - In the map world the camera tracks the moving pin, with roll following the route tangent (0.25 s lag) and a slight perspective tilt (map plane pitched ≈18°).
  - Pull-out reveals the phone again in 0.4–0.5 s (ease-out).
  - App close: the content scales down and slides up into a rounded card that leaves the top while the next colour rises from the bottom.
- T15 Logo build: the mark rises, then slides left as the wordmark un-masks; the line below fades and rises in. ≈0.85 s total.
- T16 Whip in/out: strong ease-out on entry (≈70% of the move happens in the first 0.3 s) and pure ease-in on exit, with motion blur on both. Exit up-right / entry from lower-left chain into one continuous loop.

DEVICE RIG (2.5D in Canvas 2D; this is the medium, do not switch to WebGL)
- Per-frame pipeline:
  1. Draw the stage.
  2. Render the current screen into an offscreen screen canvas SC (1080×2340 units) in screen space: wallpaper or app UI, glass panels (blurring SC's own background via blurOf), and every transition that happens inside the screen.
  3. Composite SC onto the phone at the current POSE.
  4. Draw in stage space anything that leaves the screen: flying tiles, groceries, the map world during and after the pass-through.
  5. Finishing.
- POSE = {cx, cy, s, roll, yaw, pitch}. (cx, cy) is the phone centre on the 1080×1920 frame, s maps SC units → frame px, and the angles are radians.
  - Project a phone-plane point (u, v, 0) by rotating it about x (pitch), y (yaw) and z (roll), then x' = cx + s·X·F/(F − Z) and y' = cy + s·Y·F/(F − Z), with F = 3200.
  - When |yaw| and |pitch| < 0.04, draw SC with a single affine drawImage (fast and crisp).
  - Otherwise mesh-warp SC through a 6×12 grid: two clipped affine triangles per cell, with 0.5 px overlap to hide seams.
- Poses (starting values; tune in the storyboard):
  - HERO: s 0.46, cx 540, cy 1060, roll −11°, yaw 12°, pitch 4°
  - NEAR: s 0.78, cx 540, cy 960, all angles 0. The whole phone is visible and the status bar is readable.
  - FULL: s 1.00, cx 540, cy 960. The screen fills the frame width.
  - END: s 0.62, cx 540, cy 1000, roll +6°, yaw −10°
  - Pass-through goes up to s 1.6.
  - Interpolate keyed poses with per-segment easing: ease-out for arrivals, inOut for morphs, ease-in for exits, and "dive" = a long ease-in followed by a snappy ease-out ≈ cubic-bezier(0.7, 0, 0.2, 1).
- Body:
  - Front outline: a rounded rect = SC + a 34-unit bezel; outer radius 168, screen radius 140; satin graphite #150A15 with a soft edge highlight.
  - Side wall: the band between the front outline and the same outline offset −40 units in z, drawn only where it faces the camera, with 2 buttons on the left and 1 on the right.
  - A generic pill cutout (300×88, black) at the top centre of SC.
  - No logos anywhere on the device.
- Stage:
  - pale warm-grey cyclorama: top #DAD7DA, mid #DFDCDF, a bright horizon band #F3F2F4 at ≈78% height, floor gradient down to #ABABAC
  - a soft, wide, low-contrast hover shadow behind and below the phone (rounded rect, ≈1.15× the phone size, blur 90 px, opacity ≈0.2), with no contact shadow
- Background echo (depth of field): behind the phone, draw the current BG plate. This is a blurred, enlarged copy of a screen state (blurOf at ¼ resolution, ≈40 px blur, 60–70% over the cyclorama), with the cyclorama's floor gradient on top.
  - Plates in order: the lock/home echo (0–3.70), map (3.70), food (14.20), cool neutral (18.20), produce (21.00), green home (23.85).
  - Plates change ONLY while the pose is FULL or beyond, so the swap is never visible.
  - Keep the grey floor gradient as a faint overlay on the bottom 18% of the frame, even in the map world.
- Motion blur: on fast moves only (whips, flying tiles and items, map slide-in, pass-through). Average 6–8 sub-samples of the moving layer across a 180° shutter (t ± 1/120 s), always derived from t.
- Map world: off-white ground #F8F5F1, parks #8FC767, roads #BDBEBD with a #A8A8A8 outline, route #00AA13 with a #7CF29A rim, a dashed KRL line #3A3F45, labels in grey caps #7C7C7D. Station labels are only "Stasiun".
- Pins and pucks: a coloured disc with a white glyph inside a frosted-glass ring (glass() + orb() highlights) with a soft drop shadow.
- Glass inside SC:
  - Call glass(sctx, SRC, …) where SRC = blurOf(SC background so far) built at ¼ resolution (glass() scales the source to the canvas, so a small source is fine).
  - Re-blur for glass-over-glass exactly as the reference does.

H HELPER LIBRARY (lib/harness.js; the registerStyle/H.render parts are only needed by the original gallery)
```js
// Shared helpers + style registry for the style-frame explorations.
// Every style is a pure function of time: draw(ctx, W, H, t). Same t => same pixels.
(function () {
  const STYLES = (window.STYLES = window.STYLES || []);
  window.registerStyle = (s) => STYLES.push(s);

  const H = (window.H = {});

  // ---------- seeded randomness ----------
  // H.rng(seed) -> r() in [0,1). Extras: r.range(a,b), r.int(a,b), r.pick(arr), r.gauss(), r.chance(p)
  H.rng = function (seed = 1) {
    let a = typeof seed === 'string' ? hashStr(seed) : (seed >>> 0) || 1;
    const r = function () {
      a |= 0; a = (a + 0x6d2b79f5) | 0;
      let t = Math.imul(a ^ (a >>> 15), 1 | a);
      t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
    r.range = (lo, hi) => lo + r() * (hi - lo);
    r.int = (lo, hi) => Math.floor(lo + r() * (hi - lo + 1));
    r.pick = (arr) => arr[Math.floor(r() * arr.length)];
    r.chance = (p) => r() < p;
    r.gauss = () => { let u = 0, v = 0; while (!u) u = r(); while (!v) v = r(); return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v); };
    return r;
  };
  function hashStr(s) { let h = 2166136261; for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); } return h >>> 0; }

  // ---------- gradient noise ----------
  // H.makeNoise(seed) -> { n2(x,y), n3(x,y,z), fbm2(x,y,oct), fbm3(x,y,z,oct) }  (outputs roughly -1..1)
  H.makeNoise = function (seed = 1) {
    const r = H.rng(seed), p = new Uint8Array(512), perm = [...Array(256).keys()];
    for (let i = 255; i > 0; i--) { const j = Math.floor(r() * (i + 1)); [perm[i], perm[j]] = [perm[j], perm[i]]; }
    for (let i = 0; i < 512; i++) p[i] = perm[i & 255];
    const fade = (t) => t * t * t * (t * (t * 6 - 15) + 10);
    const lerp = (a, b, t) => a + (b - a) * t;
    const g3 = (h, x, y, z) => { h &= 15; const u = h < 8 ? x : y, v = h < 4 ? y : h === 12 || h === 14 ? x : z; return ((h & 1) ? -u : u) + ((h & 2) ? -v : v); };
    function n3(x, y, z) {
      const X = Math.floor(x) & 255, Y = Math.floor(y) & 255, Z = Math.floor(z) & 255;
      x -= Math.floor(x); y -= Math.floor(y); z -= Math.floor(z);
      const u = fade(x), v = fade(y), w = fade(z);
      const A = p[X] + Y, AA = p[A] + Z, AB = p[A + 1] + Z, B = p[X + 1] + Y, BA = p[B] + Z, BB = p[B + 1] + Z;
      return lerp(lerp(lerp(g3(p[AA], x, y, z), g3(p[BA], x - 1, y, z), u), lerp(g3(p[AB], x, y - 1, z), g3(p[BB], x - 1, y - 1, z), u), v),
        lerp(lerp(g3(p[AA + 1], x, y, z - 1), g3(p[BA + 1], x - 1, y, z - 1), u), lerp(g3(p[AB + 1], x, y - 1, z - 1), g3(p[BB + 1], x - 1, y - 1, z - 1), u), v), w);
    }
    const n2 = (x, y) => n3(x, y, 0.5);
    const fbm3 = (x, y, z, oct = 4) => { let s = 0, a = 0.5, f = 1, norm = 0; for (let i = 0; i < oct; i++) { s += a * n3(x * f, y * f, z * f); norm += a; a *= 0.5; f *= 2; } return s / norm; };
    const fbm2 = (x, y, oct = 4) => fbm3(x, y, 0.5, oct);
    return { n2, n3, fbm2, fbm3 };
  };

  // ---------- math ----------
  H.lerp = (a, b, t) => a + (b - a) * t;
  H.clamp = (v, lo = 0, hi = 1) => Math.max(lo, Math.min(hi, v));
  H.map = (v, a, b, c, d) => c + ((v - a) / (b - a)) * (d - c);
  H.smooth = (e0, e1, x) => { const t = H.clamp((x - e0) / (e1 - e0)); return t * t * (3 - 2 * t); };
  H.ease = {
    inOut: (t) => (t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2),
    out: (t) => 1 - Math.pow(1 - t, 3),
    in: (t) => t * t * t,
    back: (t) => { const c = 1.70158; return 1 + (c + 1) * Math.pow(t - 1, 3) + c * Math.pow(t - 1, 2); },
  };

  // ---------- color ----------
  H.hex = (h) => { h = h.replace('#', ''); if (h.length === 3) h = h.split('').map((c) => c + c).join(''); const n = parseInt(h, 16); return [(n >> 16) & 255, (n >> 8) & 255, n & 255]; };
  H.rgba = (hexOrArr, a = 1) => { const [r, g, b] = Array.isArray(hexOrArr) ? hexOrArr : H.hex(hexOrArr); return `rgba(${r | 0},${g | 0},${b | 0},${a})`; };
  H.mix = (c1, c2, t) => { const a = Array.isArray(c1) ? c1 : H.hex(c1), b = Array.isArray(c2) ? c2 : H.hex(c2); return [0, 1, 2].map((i) => a[i] + (b[i] - a[i]) * t); };

  // ---------- canvas utilities ----------
  // Offscreen canvas of the same logical size (use for layers, masks, compositing).
  H.layer = (W, H_, ) => { const c = document.createElement('canvas'); c.width = W; c.height = H_; return c; };
  // Monochrome grain / film noise over the whole canvas. amount ~ 0.03-0.15
  H.grain = function (ctx, W, Hh, amount = 0.08, seed = 7, mono = true) {
    const img = ctx.getImageData(0, 0, ctx.canvas.width, ctx.canvas.height), d = img.data, r = H.rng(seed), k = amount * 255;
    for (let i = 0; i < d.length; i += 4) {
      const n = (r() - 0.5) * k;
      if (mono) { d[i] += n; d[i + 1] += n; d[i + 2] += n; }
      else { d[i] += (r() - 0.5) * k; d[i + 1] += (r() - 0.5) * k; d[i + 2] += (r() - 0.5) * k; }
    }
    ctx.putImageData(img, 0, 0);
  };
  // Paper-ish texture tile: fills with base color + fibrous noise (cheap; drawn into ctx).
  H.paper = function (ctx, W, Hh, base = '#f3ecdc', seed = 3, strength = 0.06) {
    ctx.save(); ctx.fillStyle = base; ctx.fillRect(0, 0, W, Hh);
    const nz = H.makeNoise(seed), cell = 4, [br, bg, bb] = H.hex(base);
    for (let y = 0; y < Hh; y += cell) for (let x = 0; x < W; x += cell) {
      const v = nz.fbm2(x * 0.01, y * 0.01, 3) * 0.6 + nz.n2(x * 0.15, y * 0.04) * 0.4;
      const s = 1 + v * strength * 2;
      ctx.fillStyle = `rgb(${br * s | 0},${bg * s | 0},${bb * s | 0})`; ctx.fillRect(x, y, cell, cell);
    }
    ctx.restore();
  };
  // Vignette
  H.vignette = function (ctx, W, Hh, strength = 0.5, color = '0,0,0') {
    const g = ctx.createRadialGradient(W / 2, Hh / 2, Math.min(W, Hh) * 0.3, W / 2, Hh / 2, Math.hypot(W, Hh) * 0.6);
    g.addColorStop(0, `rgba(${color},0)`); g.addColorStop(1, `rgba(${color},${strength})`);
    ctx.save(); ctx.fillStyle = g; ctx.fillRect(0, 0, W, Hh); ctx.restore();
  };

  // ---------- rendering entry ----------
  // Renders style into canvas at logical 1280x720 (canvas can be any pixel size; it is scaled).
  H.W = 1280; H.H = 720;
  H.loadFonts = async function (style) {
    const specs = style.fonts || [];
    try { const sample = 'AaZz09' + (window.FONT_SAMPLE || '');
      await Promise.all(specs.map((f) => document.fonts.load(f, sample))); await document.fonts.ready; } catch (e) { /* render anyway */ }
  };
  H.render = function (style, canvas, t) {
    const ctx = canvas.getContext('2d', { willReadFrequently: !!style.readsPixels });
    const sx = canvas.width / H.W, sy = canvas.height / H.H;
    ctx.setTransform(1, 0, 0, 1, 0, 0); ctx.globalAlpha = 1; ctx.globalCompositeOperation = 'source-over'; ctx.filter = 'none';
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.save(); ctx.scale(sx, sy);
    style.draw(ctx, H.W, H.H, t == null ? style.frameT || 0 : t);
    ctx.restore();
  };
})();
```

SOUND KIT (lib/sound.js)
```js
// sound.js: a small synthesized sound kit for the style explainers. Plain Web Audio, no audio files.
// Voiceover mode: SOUND.kit(ctx, { voiceover: true }) drops beds and music, plays anything marked minor
// (play(..., { minor: true }), tone/noise { minor: true }, or scheduled inside k.withMinor(() => ...)) at about 60%
// volume instead of full, and sits all effects a little lower, so the narration stays on top while the piece still
// sounds alive. In the full mix, minor sounds play at full volume. Scores can read k.vo to branch further.
// A style adds   explainerSound(k) { k.bed('room', 0, D); k.play('pop', 1.25); ... }   and the same
// call schedules into a live AudioContext (the player) or an OfflineAudioContext (the video render).
// Times are seconds on the explainer's own clock. Randomness is seeded, so every render is identical.
(function () {
  'use strict';
  const SOUND = (window.SOUND = {});
  const TINY = 1e-4;

  // seeded random in [0,1), keyed by any string
  function rand(key) {
    let h = 2166136261;
    for (let i = 0; i < key.length; i++) { h ^= key.charCodeAt(i); h = Math.imul(h, 16777619); }
    let a = h >>> 0 || 1;
    return () => { a = (a + 0x6d2b79f5) | 0; let t = Math.imul(a ^ (a >>> 15), 1 | a); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
  }

  // note names to Hz: 'A4' = 440, 'C#5', 'Eb3'
  const STEP = { C: 0, D: 2, E: 4, F: 5, G: 7, A: 9, B: 11 };
  function hz(n) {
    if (typeof n === 'number') return n;
    const m = /^([A-G])([#b]?)(-?\d)$/.exec(n);
    const semis = STEP[m[1]] + (m[2] === '#' ? 1 : m[2] === 'b' ? -1 : 0) + (Number(m[3]) - 4) * 12 - 9;
    return 440 * Math.pow(2, semis / 12);
  }
  SOUND.hz = hz;

  SOUND.kit = function (ctx, opts) {
    const o = opts || {};
    const VO = !!o.voiceover;
    const MINOR = 0.6; // voiceover-mode volume for minor sounds
    let inMinor = false;
    const gainOf = (p, d) => (p.gain == null ? d : p.gain) * (VO && (p.minor || inMinor) ? MINOR : 1);
    const T0 = (o.start || 0) - 0; // explainer time that maps to ctx time `base`
    const base = ctx.currentTime + (o.delay || 0);
    // Start times snap to the sample grid (+ a quarter sample): in Chrome a source started a hair off the grid can
    // spike to about twice its set level.
    const SR = ctx.sampleRate;
    const at = (t) => (Math.round((base + (t - T0)) * SR) + 0.25) / SR;

    // ---- buses: sfx, amb, music -> compressor -> master; one shared reverb send
    const master = ctx.createGain(); master.gain.value = o.master == null ? 0.9 : o.master;
    const comp = ctx.createDynamicsCompressor();
    comp.threshold.value = -16; comp.knee.value = 8; comp.ratio.value = 3; comp.attack.value = 0.004; comp.release.value = 0.18;
    comp.connect(master); master.connect(o.dest || ctx.destination);
    const bus = {};
    for (const [name, g] of Object.entries({ sfx: VO ? 0.7 : 0.85, amb: 0.5, music: 0.45 })) { bus[name] = ctx.createGain(); bus[name].gain.value = g; bus[name].connect(comp); }

    // generated room reverb: decaying stereo noise, darker toward the tail
    const verb = ctx.createConvolver();
    {
      const secs = 1.6, n = Math.floor(secs * ctx.sampleRate), ir = ctx.createBuffer(2, n, ctx.sampleRate);
      for (let c = 0; c < 2; c++) {
        const r = rand('verb' + c), d = ir.getChannelData(c); let lp = 0;
        for (let i = 0; i < n; i++) { const u = i / n; lp += (0.6 - 0.45 * u) * ((r() * 2 - 1) - lp); d[i] = lp * Math.pow(1 - u, 3); }
      }
      verb.buffer = ir;
    }
    const verbIn = ctx.createGain(); verbIn.gain.value = 0.9; verbIn.connect(verb); verb.connect(comp);

    // seeded noise buffers: white, pink-ish and brown
    const noiseBuf = {};
    {
      const n = Math.floor(2.5 * ctx.sampleRate);
      for (const kind of ['white', 'pink', 'brown']) {
        const b = ctx.createBuffer(1, n, ctx.sampleRate), d = b.getChannelData(0), r = rand('noise-' + kind);
        let p0 = 0, p1 = 0, p2 = 0, br = 0;
        for (let i = 0; i < n; i++) {
          const w = r() * 2 - 1;
          if (kind === 'white') d[i] = w;
          else if (kind === 'pink') { p0 = 0.997 * p0 + 0.029 * w; p1 = 0.985 * p1 + 0.032 * w; p2 = 0.95 * p2 + 0.048 * w; d[i] = (p0 + p1 + p2 + w * 0.05) * 2.2; }
          else { br = (br + 0.02 * w) / 1.02; d[i] = br * 3.2; }
        }
        noiseBuf[kind] = b;
      }
    }

    // ---- automation helpers
    // a value or [[dt, value], ...] from the voice start; ramps are exponential (frequencies)
    function sweep(param, v, t) {
      if (!Array.isArray(v)) { param.setValueAtTime(v, t); return; }
      param.setValueAtTime(v[0][1], t + v[0][0]);
```

```js
  function glowLine(ctx, a, c, b, prog, col1, col2, w = 3, dots = 0, t = 0) {
    if (prog <= 0) return null;

    const g = ctx.createLinearGradient(a[0], a[1], b[0], b[1]); g.addColorStop(0, col1); g.addColorStop(1, col2);
    ctx.save(); ctx.strokeStyle = g; ctx.lineWidth = w; ctx.lineCap = 'round'; ctx.shadowColor = col2; ctx.shadowBlur = 14;
    ctx.beginPath(); ctx.moveTo(a[0], a[1]); for (let i = 1; i <= 40; i++) { const p = q(prog * i / 40); ctx.lineTo(p[0], p[1]); } ctx.stroke();
    const e = q(prog), e0 = q(Math.max(0, prog - 0.03)), ang = Math.atan2(e[1] - e0[1], e[0] - e0[0]);
    ctx.translate(e[0], e[1]); ctx.rotate(ang); ctx.fillStyle = col2; ctx.beginPath(); ctx.moveTo(6, 0); ctx.lineTo(-8, -7); ctx.lineTo(-5, 0); ctx.lineTo(-8, 7); ctx.closePath(); ctx.fill();
    ctx.restore();

    return q;
  }
```
